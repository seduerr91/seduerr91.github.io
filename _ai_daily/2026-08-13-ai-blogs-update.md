## New Cookbook Recipes

### [README.md](https://github.com/anthropics/claude-cookbooks/blob/34fd3f6ea5e24fbcf67fc6ace4cc07a7710cec70/README.md)
**Source:** anthropics/claude-cookbooks

The Claude Cookbooks provide a comprehensive resource for developers looking to build applications with Claude. Key features include code snippets primarily in Python and guides covering topics such as text classification, summarization, and integration with external tools like databases and web pages. Users are encouraged to obtain a Claude API key and can benefit from additional resources, including a fundamentals course and community support through Discord. The project promotes community contributions to enhance its content. Notable advanced techniques include using Claude for PDF parsing, automated evaluations, and creating content moderation filters. Additional examples for leveraging Claude on AWS are also available, emphasizing its adaptability in various environments.

### [policy_manual.md](https://github.com/anthropics/claude-cookbooks/blob/34fd3f6ea5e24fbcf67fc6ace4cc07a7710cec70/cost_optimization/assets/policy_manual.md)
**Source:** anthropics/claude-cookbooks

The Acme Insurance Auto Claims Adjudication Manual (effective January 1, 2024) outlines essential coverage types, documentation requirements, and procedures for handling auto claims. Key coverages defined include Collision, Comprehensive, Liability, Uninsured/Underinsured Motorist, and Personal Injury Protection. The manual stipulates rigorous intake documentation for various claim types, such as repair estimates, police reports, and recorded statements, and emphasizes proper verification of coverage. It details payout calculation rules, including deductible applications, Actual Cash Value determinations, labor rate caps, total loss thresholds, and subrogation practices. Exclusions and denial codes are also specified to guide claims processing. This updated manual aims to streamline operations and ensure consistency in claims adjudication.
